# ABP-Smarthome-Solutions-6

Este repositorio contiene el esquema de base de datos y los datos de prueba para  sistema de gestión de hogar inteligente.

El script SQL define tablas para usuarios, roles, dispositivos, tipos de dispositivos y automatizaciones, incluyendo consultas avanzadas (JOINs y subconsultas) para analizar los datos.

No se requiere instalación local de software (como MySQL Workbench o un servidor MySQL). Solo  se necesita:

Para poder ejecutarlo vamos a necesitar:

•	Un navegador web(Chrome, Firefox, etc) y acceso a la plataforma OneCompiler para SQL.

Ejecución del Script en OneCompiler
1.	Abrimos OneCompiler a través del siguiente link: https://onecompiler.com/mysql.
2.	Tenemos que borrar todo el codigo que viene por defecto en queries.sql
3.	Copiamos todo nuestro codigo del archivo .sql 
4.	Pegamos todo el código
5.	Ejecutamos el script dandole click en el botón que dice 'RUN' que esta en la parte superior derecha de la pagina web
6. Luego nos va a dar todos los resultados a nuestra derecha inferior. ahi vamos a poder ver las consultas, tablas, multitablas y las subconsultas solicitadas para la evidencia 6
